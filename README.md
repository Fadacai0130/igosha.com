# Igosha - Investing in the Market

A comprehensive web platform for learning about market investing and calculating potential investment returns.

## Features

- **Educational Content**: Learn about the benefits of market investing
- **Investment Calculator**: Calculate potential returns based on your investment strategy
- **Investment Strategies**: Explore different approaches to market investing including:
  - Dollar-Cost Averaging
  - Buy and Hold
  - Index Fund Investing
  - Dividend Growth
  - Asset Allocation
  - Value Investing
- **Getting Started Guide**: Step-by-step instructions for beginning your investment journey

## How to Use

### Viewing the Website

1. Open `index.html` in your web browser
2. Navigate through the different sections using the navigation menu
3. Use the investment calculator to estimate potential returns

### Investment Calculator

The calculator allows you to:
- Set your initial investment amount
- Define monthly contribution amounts
- Choose your investment time horizon
- Adjust expected annual returns
- See total contributions, interest earned, and final balance

Simply open `index.html` in any modern web browser. No build process or server required.
